# Text Analysis Using Python

## Project Overview

Text Analysis is a Python-based project that performs basic analysis on a given text. The project calculates the number of words, characters, vowels, word frequency, and repeated words.

This project was developed as part of an AI & ML Internship task.

## Objective

The objective of this project is to understand basic text-processing techniques using Python and extract useful information from a given text.

## Features

- Counts total number of words
- Counts total characters
- Counts vowels
- Calculates word frequency
- Identifies repeated words
- Displays the analysis clearly

## Technologies Used

- Python
- Google Colab

## Python Concepts Used

- Strings
- Lists
- Loops
- Conditional Statements
- Dictionaries
- String Processing

## How the Project Works

1. A sample text is provided as input.
2. The text is converted into lowercase.
3. Basic punctuation is removed.
4. The text is split into individual words.
5. The total number of words is calculated.
6. Characters excluding spaces are counted.
7. Vowels are counted using a loop and condition.
8. Word frequency is calculated using a dictionary.
9. Repeated words are identified.
10. The final analysis is displayed.
